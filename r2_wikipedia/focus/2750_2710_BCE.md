# 2750 to 2710 BCE — five partial steps

I worked on **2750, 2740, 2730, 2720 and 2710 BCE**. The five year pages and their decade pages all lead to the same Wikipedia century page.

## Game history updated

- **Keros and Dhaskalio, Greece:** Added a note about an early archaeological phase dated approximately **2750–2550 BCE**. The start date is uncertain. This is a period of evidence, not proof of a separate event in each year.
- **Tyre, Lebanon:** Corrected an old entry to say that **c.2750 BCE** is a traditional estimate of the city's founding, not a verified exact date. It no longer incorrectly triggers a political treaty effect.
- **Dhaskalio:** Removed an unsupported Minoan label from the site's game data. Other site details and possible game fallbacks still need checking.

The previous batch also corrected an uncertain **2750 BCE** date for the end of the Cucuteni–Trypillia culture.
