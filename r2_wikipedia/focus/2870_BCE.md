# 2870 BCE — partial ten-year step

## History improved in the game

I updated **two existing entries**:

- **Dholavira, India:** its early-site note now covers an approximate period that includes 2870 BCE. Archaeologists use different dates for its early phases; the note does **not** prove it was inhabited every year or that its later city existed in 2870.
- **Egyptian calendar:** I corrected an old date and removed a mix-up between the civil and lunar calendars. Around 2874 BCE is shown only as **one uncertain estimate** for the civil calendar’s origin.

The Dholavira note can appear in the game across multiple years; it does not describe an event repeated every year. The changes have not been tested in an existing save.

Sources include [Wikipedia’s Dholavira article](https://en.wikipedia.org/w/index.php?title=Dholavira&oldid=1380144703), [UNESCO](https://whc.unesco.org/en/list/1645/), and [Wikipedia’s Egyptian calendar article](https://en.wikipedia.org/w/index.php?title=Ancient_Egyptian_calendar&oldid=1373218552).
